## How to Run

```bash
pip install -r requirements.txt
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

Then visit: http://localhost:8000

## Testing the System

```bash
# Upload a ZIP with documents
# Watch progress bar update
# Click Pause/Resume/Cancel if desired
# View results preview
# Download CSV when complete
```

## Features

1. Clean, modern web interface
2. Real-time progress tracking
3. Document similarity detection (0.20+ Jaccard threshold)
4. CSV export with clean filenames
5. Pause/Resume/Cancel processing
6. Browser notifications on completion
7. Fully responsive design
8. Lightweight (no frameworks, pure FastAPI)

## Stack

- FastAPI backend
- HTML/CSS/Vanilla JavaScript frontend
- Threading for background processing
- No external UI libraries
- No databases required
